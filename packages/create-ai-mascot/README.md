# create-ai-mascot

Set up an [ai-mascot](https://github.com/YUALAB/ai-mascot) server in one minute.

```bash
npx create-ai-mascot
```

Pick an AI (Ollama, OpenAI, Claude or Gemini), paste your key (saved only in `.env`), enter your site URL — and you get a folder with `npm start` and `npm run index` ready to go.
